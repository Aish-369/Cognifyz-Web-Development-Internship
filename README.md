
# Cognifyz Technologies – Web Development Internship

A collection of web development projects created as part of the Cognifyz Technologies internship tasks.

## About the Project

This repository contains practical assignments focused on HTML, CSS, JavaScript, front-end frameworks, responsive web design, image manipulation, and landing page development.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bulma
- CSS Grid and Flexbox
- CSS Media Queries

## Internship Tasks

### Level 1 – Beginner

**Task 1: HTML and CSS**
- Basic webpage structure
- Image and paragraph
- HTML form
- Navigation links

**Task 2: JavaScript**
- Dynamic button color changer
- Time-based greeting alert
- Addition calculator

### Level 2 – Intermediate

**Task 1: Front-end Frameworks**
- Responsive Bulma card component
- Bootstrap responsive grid layout

**Task 2: Responsive Design**
- Responsive webpage using media queries
- Mobile-friendly hamburger navigation

### Level 3 – Advanced

**Task 1: Image Manipulation**
- Interactive CSS image gallery
- Enlarged image preview
- Automatic CSS slideshow

**Task 2: Landing Page**
- Internship introduction
- Program highlights
- Relevant qualifications
- Call-to-action buttons
- Contact information

## How to Run

1. Clone or download the repository.
2. Open the project folder in Visual Studio Code.
3. Navigate to the required task folder.
4. Open `index.html` using Live Server or a web browser.

Note: Some projects require an internet connection to load external images, fonts, or CSS frameworks.
