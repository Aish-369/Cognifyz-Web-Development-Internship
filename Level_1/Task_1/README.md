# Cognifyz Web Development Internship — Level 1, Task 1

## PDF requirements
1. A simple webpage with a heading, paragraph, and image using HTML and CSS.
2. A basic form with a single input field and a submit button.
3. A simple navigation menu with three links.

## Files
- `index.html`: semantic HTML and a tiny script for a local demo form.
- `style.css`: responsive layout, colors, typography, and components.
- `developer.svg`: original local illustration; no internet needed.

## Run
Open `index.html` in a browser, or use VS Code Live Server. No installation needed.

## Test
- Click Home, About, Contact navigation links.
- Check heading, paragraph, and image.
- Try submitting an invalid email, then a valid email.
- Resize browser to phone width to check responsive behavior.

**Note:** This is a frontend-only demonstration. No email is transmitted or stored. The script prevents page reload and displays a local confirmation.

Review, understand, and personalize this project before submitting it as your own work.
